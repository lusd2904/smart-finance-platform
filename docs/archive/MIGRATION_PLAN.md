## 四、原则

1. **能复用现有 Influx / 舆情 / 长桥配置，不重复造中间层 MySQL 行情。**  
2. **交易类能力单独权限与审计，不与舆情混菜单。**  
3. **每阶段：菜单 SQL + 前端路由 + 接口 + 深色验收 + 冒烟脚本。**  
4. **原项目只读对照，移植时按 RuoYi 分层（controller/service/dao/vue）落地。**
