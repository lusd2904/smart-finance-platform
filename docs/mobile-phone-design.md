# 手机端逐页设计（落地稿）

外部 CLI 调用记录见文末。设计主体来自仓库 `设计稿.md` 2.3 / 3.x 移动端条款，并据此已开始改 Flutter。

## 1. 信息架构（4 Tab）

| Tab | 路由 | 说明 |
|---|---|---|
| 工作台 | `/portal` | 门户卡片入口；抽屉里仍可开量化/舆情/系统 |
| 行情 | `/market/heat` | 热度首页；内部再进行情台、K 线、全部股票 |
| 自选 | `/market/watchlist` | 分组 chip + 标的列表，点进 K 线 |
| 我的 | `/user/profile` | 账号、网关、退出 |

- 顶栏汉堡：RuoYi 全量菜单（量化、舆情、系统等不进底栏）
- 非根页（K 线、下单）：顶栏返回，底栏仍在
- 弹窗：底部抽屉，禁止居中 Dialog
- 令牌：`#409EFF` / 涨 `#E5484D` / 跌 `#30A46C`

## 2. 工作台 / 门户

- 全宽卡片列表，标题 22sp
- 卡片内链接折行，不固定 360 宽
- 主手势：点卡片进模块，点链接进子页

## 3. 行情热度 / 行情台

- 顶：三市场 Segment（US/HK/CN）
- 中：指数条横向滑
- 下：热度/涨跌列表，行高可点
- 行情台后续：搜索 + 自选列表，不并排三栏

## 4. 自选

- 顶部分组 chip 横滑
- 列表：代码、现价、涨跌%，右滑删除（后续）
- 点行 → K 线

## 5. K 线

- 顶：代码 + 现价涨跌
- 周期 Segment：分时/日/周/月
- 图全宽
- 底：加自选 / 交易（进交易台并带 symbol）

## 6. 交易终端

- 已拆：自选 | K线 | 交易
- 底保留盘口高度压缩
- 下单走底部抽屉（后续）

## 7. 持仓 / 委托

- 单列卡片，不用宽表
- 筛选收进顶栏「筛选」抽屉

## 8. 舆情大盘

- 情绪仪表 + 三市场卡竖排
- 资讯流无限列表
