# 行情中心使用说明

## 这个模块做什么

三市场热度与 Top50、行情台、自选清单、全部股票、智能选股、资金与日历、财经资讯。列表浏览走库与行情通道；长桥只用于交易台实时报价和下单。

## 使用前

- 登录账号须有「行情中心」菜单。无入口找管理员开菜单，不要改别人账号。
- 智能选股 / 自选分析读「AI 管理 → 模型管理」里适用范围为 **行情中心 (market)** 的模型，默认 Grok 4.6（OpenRouter 编码 `x-ai/grok-4.6`，直连 xAI 填 `grok-4.6`）。未配则回退全局 / 助手。
- 自选与量化扫描池都走当前账号的 `market_watchlist`，账号之间隔离。
- Influx 未就绪时登录仍可用，K 线 / 热度可能 502，等时序库起来再刷。

## 操作步骤

1. **市场热度**：侧栏「行情中心 → 市场热度」。切 A股 / 港股 / 美股，看指数涨跌、成交额、涨跌家数、热度分与成交额 Top50。可选交易日、刷新。盘中有指数条（每市场三条：美股标普/纳指/道琼斯，港股恒指/恒科/国企，A 股上证/创业板/科创板）。Top50 行内可进详情、K 线或加自选。
2. **行情台**：侧栏「行情中心 → 行情台」。筛选市场或代码/名称，点 **K线** / **详情** / **AI研判**。报价读缓存与行情通道，不是长桥列表 overlay。
3. **自选清单**：侧栏「行情中心 → 自选清单」。左栏按分组筛选（分组名逗号分隔，如 `七巨头,持仓`），中栏日/周/月 K，右栏报价、备注与综合分析。可「新增自选」「立即分析全部」「建议回测」。下方「自选相关热力」是本账号自选日收益相关（最多 16 只）。最新价走实时通道。
4. **全部股票**：侧栏「行情中心 → 全部股票」。美/港/A 分页浏览，搜代码或名称，点 **加自选** 或进 K 线/详情。表上「最新价」取本地日 K，不是盘中实时。
5. **智能选股**：侧栏「行情中心 → 智能选股」。点「刷新情绪」「生成选股单」，或按交易日看历史。入选标的走 AI 研判（指标 + 舆情 + 开盘指数）；休市市场自动去掉指数，仍可手动出单。HTTP 只回队列票，页面刷新看结果。定时 cron 在「任务中心 → 自动分析任务」改（默认北京时间 15:50 / 16:50 / 05:50）。
6. **资金与日历**：侧栏「行情中心 → 资金与日历」。看 A 股板块资金 treemap、涨停池、龙虎榜（东财），以及 Nasdaq 宏观/美股财报日历。源失败时是空表，不是 502。点行可进对应标的。
7. **财经资讯**：侧栏「行情中心 → 财经资讯」。按市场看简报流，关键词可过滤标题/摘要/标的；个股详情会叠该代码相关简报。
8. **顶栏搜索**：⌘K / Ctrl+K 搜本账号有权限的菜单（Bloomberg 命令栏习惯）。
9. **手机**：底栏 **自选 / 行情 / 选股 / 持仓 / 我的**。行情默认 A 股；自选顶栏指数为上证 / 恒生 / 纳指，表头可按名称、最新、涨跌幅排序，左滑或长按删自选。搜索页可加自选。点行进个股（大字现价、周期含 5 分/15 分、星标加自选）。桌面宽屏登录后是同一套 Web 控制台。

## 注意

- 紧急停机（Halt）只拦新单，不拦撤单。开关在「量化交易 → 策略配置」或手机「我的」。
- 自动交易默认纸面（开关关闭只扫描不下单）。打开后按本账户长桥凭据下到模拟或真实账户。
- A 股不参与自动交易扫描与下单。
- 策略档（保守 / 均衡 / 进取）按登录账户绑定；行情自选也按账号隔离。
- 运维更新不要 `compose down`，不要重建 MySQL / Redis / Influx。
- 涨跌颜色：涨红跌绿。
- 手机底栏是 **自选 / 行情 / 选股 / 持仓 / 我的**（舆情在「我的」）。

## 常见问题

1. **热度是空的？** 收盘采集任务还没跑，或 Influx 未就绪。看「任务中心 → 自动分析任务」里 A/港/美收盘热度是否启用、上次是否成功，页面点刷新。
2. **全部股票的最新价怎么不动？** 该页走本地日 K。盘中现价看行情台、自选清单、交易台或手机自选（行情 WS）。
3. **为什么看不到同事的自选？** 按登录账号隔离，不会混池。
4. **⌘K 搜不到某个菜单？** 当前角色没有该菜单权限。
5. **点「生成选股单」立刻没结果？** 已入后台队列。状态可能是 `retrying`（还在重试），不是失败。过一会儿刷新本页，或到「任务中心 → 自动分析任务」看「全市场智能选股」。
