# 交易中心使用说明

## 这个模块做什么

长桥账户下的交易台下单、持仓、委托、紧急停机与仓位护栏。配了模拟账户就是模拟，配了真实账户就是真实；平台不再另套一层纸账户。

## 使用前

- 须有「交易中心」菜单，以及本账号「量化交易 → 长桥配置」里的 App Key / Secret / Token（每人一行，互不可见）。
- 手工买入与自动交易共用护栏：日内名义本金、单票仓位（默认净资产 **10%**，可在策略配置调 5%–30%）、总敞口、可用现金。卖出校验可用持仓。拦截在服务端，不打长桥。
- 自动交易开关默认关（纸面：只扫描不下单）。打开后扫美/港热度 Top50（可叠加本账户美/港自选），**A 股不扫、不下单**。已持仓或当日已买入的标的不再加仓。
- 门户「行情交易」与侧栏交易台都进 `/trade/terminal`。旧地址 `/trade/trading`、`/trade/desk` 会重定向。

## 操作步骤

1. **券商账户**：侧栏「交易中心 → 券商账户」。看长桥是否已配置，可连通测试，再进交易台。老虎 / 富途未接入。改 Key 仍去「量化交易 → 长桥配置」。
2. **交易台**：侧栏「交易中心 → 行情交易」（即交易台）。顶栏搜全市场代码，左侧自选按分组，中间 K 线/分时，右侧盘口、逐笔与下单。打开默认第一只自选。旁路「量化」开关即本账户自动交易（无 Key 时灰显）。右上角 `LIVE` / `无数据` 表示是否拉到真实行情，没有随机假价。
3. **下单**：选买入/卖出、限价 LO 或市价 MO，填价格与数量。25% / 50% / 75% / 全仓按**购买力**（买入）或可卖数量（卖出）算股数，A 股按 100 股一手向下取整，不要把百分比当成股数。提交走当前用户长桥账户。
4. **紧急停机**：侧栏「量化交易 → 策略配置」或手机「我的」打开停机。拦住手工单、自动扫描、次日清单；**撤单仍可用**（交易台当日委托、订单页、手机持仓当日委托）。
5. **持仓**：侧栏「交易中心 → 持仓」。长桥真实持仓叠现价，自算涨跌与浮动盈亏。点「交易」进交易台对应标的。空表会有提示。
6. **订单**：侧栏「交易中心 → 订单」。今日 / 历史委托；今日在途单可撤。
7. **美股延长时段**：实盘美股按当前时段传长桥 `outside_rth`（盘前/盘后 AnyTime，夜盘 Overnight）。港股 / A 股不传该参数。周日 20:00 ET 起客户端标「夜盘」而不是「休市」。
8. **手机持仓**：底栏「持仓」。点持仓进详情，点「交易」才出极速单（限价 + 仓位比例）。港元/美元文字切换。百分比同样按购买力或可卖数量，不是把 25 写成 25 股。

## 注意

- 紧急停机（Halt）只拦新单，不拦撤单。
- 自动交易默认纸面（开关关闭只扫描不下单）。打开后按本账户长桥凭据下到模拟或真实账户；前端关掉开关关不掉服务端拦截。
- A 股不参与自动交易扫描与下单。
- 策略档按登录账户绑定；交易台量化开关与次日清单都用该档，不再写死 balanced。
- 运维更新不要 `compose down`，不要重建 MySQL / Redis / Influx。
- 涨跌颜色：涨红跌绿。
- 手机底栏是 **自选 / 行情 / 选股 / 持仓 / 我的**。
- 长桥**模拟账户**不撮合美股盘前、盘后、夜盘，只在常规盘（09:30–16:00 ET）模拟成交。延长时段下单可能被拒或一直挂着，这是券商限制。

## 常见问题

1. **停机后撤不掉单？** 停机只拦新委托。今日在途单在订单页或持仓「撤单」提交。
2. **模拟盘夜盘为什么不成交？** 长桥模拟只撮合美股常规盘。要练延长时段用实盘 Key，或等到常规盘。
3. **点了 25% 股数不对？** 按可用购买力（或可卖数量）折股，A 股再按 100 股取整。不是把百分比数字写进数量框。
4. **下单提示超过单标的仓位？** 默认同一只股票持仓市值不超过净资产 10%（策略配置可调）。总持仓达到或超过净资产、可用现金不足时也会停买。拦截发生在打长桥之前。
5. **持仓现价不跳？** 需已配长桥且行情通道已订阅该标的。未配凭证时持仓页会提示；空表不是报错。
