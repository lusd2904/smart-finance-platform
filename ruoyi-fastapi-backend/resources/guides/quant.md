# 量化交易使用说明

## 这个模块做什么

按登录账户绑定策略档，对**本账号自选**做因子计算、策略信号、扫描台账和次日清单。定时扫描、自动交易、次日清单、回测默认走该账户生效档。

## 使用前

- 须有「量化交易」菜单。扫描池是当前账号「行情中心 → 自选清单」，不是全市场精选池，也不是别人的自选。旧表 `quant_watchlist` 只读保留，侧栏「自选池」已隐藏。
- 先在「量化交易 → 策略配置」点 **设为生效**，三档编码：`conservative` 保守 / `balanced` 均衡 / `aggressive` 进取。未绑定则默认均衡。权重覆盖只属于本账户。
- 要真实委托：先在「量化交易 → 长桥配置」填本账号 App Key / Secret / Token（保存时 `****` 不覆盖原密钥），再在策略配置打开自动交易。未配 Key 时开关打不开。
- 因子 / 回测依赖 Influx 日 K。回测入口在「交易中心 → 策略回测」，不在本目录。

## 操作步骤

1. **策略配置**：侧栏「量化交易 → 策略配置」。三张档位卡改买入/卖出阈值与 8 族权重（趋势、价型、动量、突破、量能、回归、波动、流动性），点 **保存档位**，再 **设为生效**。本页同时有本账户自动交易开关、紧急停机、日内买入仓位（默认净资产 20%）、单标的仓位上限（默认 10%，5%–30%）。
2. **因子分析**：侧栏「量化交易 → 因子分析」。选标的点「计算因子」；「全市场日扫」入队，不要等同步算完。可导出快照。质检 IC/IR、五分位收益由任务中心的「因子质检」定时跑。
3. **策略信号**：侧栏「量化交易 → 策略信号」。页面上另选档位只覆盖**这一次**运行；不选则用绑定档。历史只看本账户。
4. **扫描台账**：侧栏「量化交易 → 扫描台账」。只读。展开一行看机会标的、候选、跳过原因与所用档位。列表只含本账户。
5. **次日策略清单**：侧栏「量化交易 → 次日策略清单」。点「扫描清单」生成本账户下一交易日标的；勾选后「勾选开仓」或「开仓并加入持续清单」（写入行情自选）。自动交易未开则不会向长桥下单。非交易日与空结果静默。
6. **回测**：侧栏「交易中心 → 策略回测」。用 8 族因子 + 策略档阈值对 Influx 日 K 做多回测，历史只看本登录账户。页面可选档覆盖这一次；默认带出绑定档。不再用 MA5/MA20 金叉。
7. **长桥配置**：侧栏「量化交易 → 长桥配置」。每人一行凭据。连通测试只打当前用户。jobs 无登录上下文时回退 admin。
8. **手机**：底栏「我的 → 量化研究」看只读信号/因子/台账；自动交易与紧急停机在「我的」。改档位、开仓仍用 Web「策略配置 / 次日策略清单」。

## 注意

- 紧急停机（Halt）只拦新单，不拦撤单。
- 自动交易默认纸面（开关关闭只扫描不下单）。打开后按本账户长桥凭据下到模拟或真实账户。
- A 股不参与自动交易扫描与下单（扫描池是美/港热度 Top50，可叠加本账户美/港自选）。
- 策略档按登录账户绑定；扫描台账 / 策略历史 / 通知 / 风控 / 回测都只看本账户。
- 运维更新不要 `compose down`，不要重建 MySQL / Redis / Influx。
- 涨跌颜色：涨红跌绿。
- 手机底栏是 **自选 / 行情 / 选股 / 持仓 / 我的**。

## 常见问题

1. **扫描扫到了别人的票？** 不应发生。未指定用户时不会把所有自选混在一起跑。确认你登录的是自己的账号，自选在「行情中心 → 自选清单」。
2. **次日清单勾了开仓没委托？** 先配长桥 Key，再在「策略配置」打开本账户自动交易。紧急停机开着时新单也会被拦。
3. **回测入口在哪？** 「交易中心 → 策略回测」，不在量化侧栏。
4. **改了权重但定时任务还是旧档？** 权重保存只改本账户覆盖；定时任务用的是 **设为生效** 的那一档。页面上单次另选档不会改绑定。
5. **空池还在扫全市场？** 不会。没有本账号自选时策略空池不再回落到精选池。先加自选再跑。
