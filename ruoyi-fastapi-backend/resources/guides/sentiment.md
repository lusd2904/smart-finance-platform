# 舆情分析使用说明

## 这个模块做什么

采集中文财经资讯，对美/港/A 做大盘影响研判，并保留分析历史。财经简报可按标的过滤；macOS Widget 用短期 Token 拉只读大盘聚合。

## 使用前

- 须有「舆情分析」菜单。「立即采集 / 立即分析」需要对应按钮权限。
- 模型在「AI 管理 → 模型管理」配。舆情优先适用范围 `sentiment`，否则 Grok 4.6 → 全局 → 助手。本目录「AI配置」页只读，改模型去 AI 管理。
- 定时采集在「任务中心 → 自动分析任务」的「舆情采集与AI分析」（默认每 10 分钟）。页面点立即分析同样入后台队列。
- Widget 只读。空 token 即关闭；不要再配环境变量固定 Token。

## 操作步骤

1. **舆情大盘**：侧栏「舆情分析 → 舆情大盘」。看总资讯、今日新增、待分析，以及美股 / 港股 / A 股影响分与方向。盘中叠指数条。点「立即采集」「立即分析」，然后刷新看卡片与趋势，不要等 HTTP 同步算完。
2. **资讯列表**：侧栏「舆情分析 → 资讯列表」。按来源（东方财富 / 新浪 / 同花顺 / 华尔街见闻 / 谷歌新闻 / 金十）、标题、是否已分析、发布时间筛选。可「手动采集」、删选中行。点标题看正文。时间按北京时间展示。
3. **分析历史**：侧栏「舆情分析 → 分析历史」。按状态与时间筛历史研判，点行看三市场分数、摘要、所用模型。可再点「手动分析」。
4. **简报按标的**：行情侧栏「行情中心 → 财经资讯」用关键词过滤标题/摘要/标的；个股详情会叠财经简报和舆情里提到该代码或名称的条目。接口也可带 `?symbol=`。
5. **Widget（只读）**：`POST /sentiment/widget/token` 用与同步接口相同的 RSA-OAEP + AES-256-GCM 信封提交用户名密码，换 60 分钟 JWT；再 `GET /sentiment/widget/dashboard`，Header `Authorization: Bearer`。明文密码会被拒绝。流程见 `docs/sentiment-widget-api.md`。
6. **手机**：底栏「我的 → 舆情 / 资讯」。影响分统一 0–100（50 中性）。历史 ±10 行按手机映射换算（-10→0、0→50、10→100）。

## 注意

- 紧急停机（Halt）只拦新单，不拦撤单（与舆情采集无关）。
- 自动交易默认纸面；A 股不参与自动交易扫描。策略档按登录账户绑定。
- 运维更新不要 `compose down`，不要重建 MySQL / Redis / Influx。
- 涨跌颜色：涨红跌绿。
- 手机底栏是 **自选 / 行情 / 选股 / 持仓 / 我的**（舆情在「我的」）。
- 舆情 `pub_time` 无时区时按北京墙钟存和展示，**不要再 +8**。长桥 / Influx 的 UTC 才会转北京时间。

## 常见问题

1. **大盘一直「暂无」？** 先采集再分析。看待分析数；任务中心该 Job 是否在线。限流时页面会倒计时，不要连点。
2. **时间差了八小时？** 资讯发布时间按北京墙钟，不是 UTC+8 再转一次。
3. **Widget 拉不到数据？** 必须先加密换令牌再带 Bearer。令牌 60 分钟过期后重换。接口只读大盘聚合，不能采集或下单。
4. **简报里没有某只股票？** 用财经资讯关键词或个股详情「相关资讯」。没有提到该代码/名称的条目不会出现。源 429 时给空列表，不是整页打挂。
5. **点分析没有立刻出分？** 任务在后台跑。刷新大盘或分析历史；ticket 为 `retrying` 表示还在重试，不是 `failed`。
